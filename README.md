# Sharkie

A small browser game built as a learning project to practice object-oriented programming in JavaScript.

## About

Help Sharkie become the hero of the seas. Move, attack, and defeat the giant shark.

## Technologies

- JavaScript
- HTML5 Canvas
- CSS

## OOP Structure

- `World` – game state, rendering loop, and entities
- `Character` – playable character
- `Enemy` – enemies
- `MovableObject` – moving game objects
- `DrawableObject` – drawable entities

## Run locally

Clone the repository and open `index.html` in a browser.

Works on desktop and mobile.
